Entry for the [make.fun bounty "Make the AI Judge Laugh: Cat Reviews Its Human"](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990): one funny single-line one-star review from a house cat about its human, under 200 characters.

## The review

> One star: the food bowl sat empty for eleven whole minutes, and when I filed my complaint, my human had the nerve to be asleep.

(127 characters, one line, plain ASCII.)

## How it works

`main.py` (Python 3.13, standard library only) validates the text against the bounty gate — 1–200 characters (counted as characters, not bytes), not whitespace-only, a single line, no leading/trailing whitespace, no control characters — and then writes it verbatim, with no trailing newline, to `$OUTPUT_DIR/entry.txt` (default `/output`). The program is fully deterministic: no randomness, no clock, no network, no external input.
